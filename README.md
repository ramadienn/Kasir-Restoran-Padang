# 🍚 Rumah Makan Padang – Sistem Informasi Restoran

Sistem informasi web berbasis **PHP** dan **MySQL** untuk mengelola operasional harian Rumah Makan Padang.
Aplikasi ini mencakup halaman beranda interaktif, sistem autentikasi pengguna (**Admin & Petugas**), serta **Dashboard Admin** untuk pengelolaan transaksi, laporan, filter data, dan cetak struk/laporan.

Dibangun menggunakan **HTML**, **Tailwind CSS**, dan **JavaScript** untuk tampilan modern, responsif, dan nyaman digunakan.

---

## 🚀 Fitur Utama

* **Beranda Interaktif**
  Landing page modern dengan **Tailwind CSS** dan efek visual yang bersih.

* **Cinematic Preloader**
  Animasi pembuka ± **3,5 detik** untuk kesan profesional saat aplikasi pertama kali dibuka.

* **Sistem Autentikasi (Multi-Role)**
  Login terpisah untuk **Admin** dan **Petugas**.

* **Private Staff Portal**
  Area login dilengkapi **pop-up peringatan otomatis** bahwa sistem hanya untuk pegawai.

* **Dashboard Admin Komprehensif**

  * Laporan transaksi (harian & bulanan)
  * Filter data transaksi
  * Cetak struk & laporan
  * Manajemen menu & stok *(dalam pengembangan)*

* **Dashboard Petugas** *(dalam pengembangan)*

## ▶️ Cara Menjalankan Aplikasi

1. Siapkan server lokal (**XAMPP / WAMP / Laragon**).
2. Impor database dari file `database.sql`
   (tabel: `users`, `menus`, `transactions`, `transaction_items`).
3. Konfigurasikan koneksi database pada file `koneksi.php`.
4. Jalankan aplikasi melalui browser:

   ```
   http://localhost/Kasir/
   ```
